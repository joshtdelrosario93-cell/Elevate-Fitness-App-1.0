# Elevate Fitness App

A single-file fitness tracker: calories eaten and burned, exercise, rest and sleep, weight and BMI, weight-loss progress, reminders, trend insights, and a friends leaderboard.

## Features
- Daily log for food, exercise, sleep, resting heart rate and rest days
- Weight tracking with BMI scale and healthy-weight range
- Progress view with pace, goal-date estimate and 7-day charts
- In-app reminders (stand up, log meals, daily active-minutes target)
- Automatic trend insights for sleep, resting heart rate, calories and weight
- Profile with photo, personal details and a calorie estimate
- Custom colors and light/dark mode, using the Elevate palette

## Run it
Open `index.html` in any browser. Data is saved in the browser's localStorage.

## Claude-hosted features
These only work when the page is published as a claude.ai artifact, and are hidden elsewhere:
- Account sign-in, name and photo, and private cross-device sync
- "Ask Claude" trend analysis
- Community leaderboard and activity feed
